# mactools

[中文](README.md) | **English**

Everyday macOS productivity tools, accessed quickly through Raycast.

## File Operations (file/)

| Script | Function |
|------|------|
| `file_copy.py` | Copies files selected in Finder |
| `file_print.py` | Prints files selected in Finder |
| `folder_paste.sh` | Pastes clipboard files into the current Finder directory |

> The Downloads cleanup trio (`downloads_organizer.py` / `smart_rename.py` / `file_cleanup-downloads.sh`) was retired on 2026-06-01 and replaced by content-router in the dev repository.

## System Tools (system/)

| Script | Function |
|------|------|
| `sys_app_launcher.py` | Application launcher |
| `display_1080.sh` | Switches the display to 1080p |
| `display_4k.sh` | Switches the display to 4K |
| `dingtalk_gov.sh` | Launches government DingTalk |
| `create_reminder.sh` | Creates Apple Reminders |

## Window Management (window/)

| Script | Function |
|------|------|
| `window_yabai.py` | Unified Yabai window-management tool (floating, follow mouse, layout switching, etc.) |

## Shared Libraries (lib/)

clipboard, display, env, file_ops, finder, usage_log, llm_client, common.sh
